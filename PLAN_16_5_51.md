## Context Extraction Implementation Detail

The helper function needs to:

```python
def extract_prerequisite_values(contract, body):
    """Extract actual prerequisite values from a body for admission verification.
    
    Args:
        contract: CapabilityContract with prerequisites tuple
        body: dict representing current Serum state
    
    Returns:
        Dict[field_path, actual_value] for proposed_prerequisites_verified
        
    Raises:
        ValueError if a prerequisite field_path cannot be resolved or is missing
    """
    if not contract.prerequisites:
        return {}
    
    result = {}
    for prereq in contract.prerequisites:
        field_path = prereq.get("field_path")
        if not field_path:
            continue
        
        # Navigate body using dotted field_path
        parts = field_path.split(".")
        node = body
        for part in parts:
            if not isinstance(node, dict) or part not in node:
                # Field missing in body → prerequisite cannot be verified
                # Return empty result; admission.py will reject it
                return {}
            node = node[part]
        
        result[field_path] = node
    
    return result
```
